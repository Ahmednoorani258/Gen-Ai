# Kabajees Clone with Dialogflow Chatbot Integration

Hi there! 👋  
This is a simple Kabajees website clone I built to practice my frontend and AI chatbot skills.  
Along with building a responsive UI, I also integrated a live chatbot using **Dialogflow**.

## What I Built

- A fully responsive clone of Kabajees homepage
- A working chatbot using **Dialogflow Messenger**
- Chatbot collects user's **name, email, and phone number**
- It can also answer FAQs by using a knowledge base setup inside Dialogflow
- Rich and friendly responses — cards, quick replies, and suggestions
- Clean and mobile-friendly UI design

## Tech Stack

- HTML
- CSS
- JavaScript
- Dialogflow ES (for the chatbot)

## Why I Built This

I wanted to practice both frontend development and AI chatbot integration in one project.  
Working on this helped me learn:
- How to connect Dialogflow with a website
- How to design custom intents and capture user details
- How to make the chatbot conversation feel natural and helpful
- Responsive web design basics

## Things I'm Proud Of

- Managed to capture user information using the chatbot and store it inside Dialogflow
- Created a smooth mobile and desktop experience
- Learned how rich responses make chatbot conversations much better
